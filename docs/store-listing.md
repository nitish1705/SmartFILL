# Chrome Web Store listing (draft — publish as **Unlisted** first)

## Name
SmartFill — safe, private form autofill

## Short description (≤ 132 chars)
Fills web forms from a profile you verify. Local-first, never submits, leaves unknown fields blank. Built for research portals.

## Detailed description
SmartFill remembers your details once and fills them into forms — including forms that label things differently (“Affiliation”, “Institution”, “University”).

**Careful by design**
- Fills only what it is sure about; less certain matches go to a review panel you control.
- Details you never entered are left blank — it never guesses or invents.
- Never submits a form. Never touches passwords, card numbers, one-time codes or ID numbers.
- One-click undo.

**Made for research submission**
- Several author profiles and a paper submission with author order and a corresponding author.
- Fills author block 1 from author 1, block 2 from author 2 … and ticks only the corresponding author’s box.
- Notices fields added later (“Add author”).

**Private**
- Your profile stays on your device. No account, no servers, no analytics.
- Matching runs locally with a small bundled model.
- Optional passphrase lock (AES-256-GCM), encrypted export, delete-everything button.
- Import details from a CV (PDF/text) in your browser — you approve every value.
- Optional AI assist is off by default and never sees your details — only field labels and candidate field names.

## Permission justifications (for the review form)
| Permission | Justification |
|---|---|
| `activeTab` | Access the current page’s form only after the user clicks the toolbar button or presses the shortcut. |
| `scripting` | Inject the fill script into that tab on demand. |
| `storage` | Store the user’s profiles, submissions and settings locally. |
| `offscreen` | Host the on-device matching model (WebAssembly) in an offscreen document. |
| optional hosts | Requested at runtime only if the user enables AI assist, for the single endpoint they enter. |
| Remote code | None. All code and the model are bundled; CSP is `script-src 'self' 'wasm-unsafe-eval'`. |

## Single purpose statement
Fill web forms with the user’s own saved profile information, on demand and with user review.

## Data-usage disclosures
Collects: none (no data is transmitted to the developer). Optional: field labels and candidate field names to a user-configured endpoint if AI assist is enabled. Certify: not sold, not used for unrelated purposes, not used for creditworthiness.
